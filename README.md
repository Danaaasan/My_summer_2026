# Как я провёл лето — Dana San Visuals

Статический сайт-портфолио на тему «Как я провёл лето».

## Технологии
- HTML5
- CSS3 (адаптив, media queries)
- Google Fonts (Pacifico, Poppins, Kalam и др.)

## Структура
- `index.html` — разметка
- `style.css` — основные стили
- `styleguide.css` — переменные
- `globals.css` — сброс + шрифты
- `img/` — изображения
